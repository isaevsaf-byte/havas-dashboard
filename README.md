# Havas Analytics — дашборд

Веб-панель посещаемости магазинов: сколько людей вошло, когда приходят,
какая доля возвращается, работает ли система на точках.

Данные читаются из Supabase, куда их пишет сервис подсчёта — он живёт в
отдельном закрытом репозитории вместе с боевой конфигурацией. Здесь только
отображение: ни ключей, ни адресов камер, ни логики подсчёта.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Без ключей Supabase страница попросит их настроить. Посмотреть, как всё
выглядит, можно на сгенерированных данных:

```bash
HAVAS_DEMO=1 streamlit run app.py
```

## Настройка

Ключи задаются переменными окружения или, на Streamlit Cloud, в
**App settings → Secrets**:

```toml
SUPABASE_URL = "https://xxxxx.supabase.co"
SUPABASE_KEY = "..."
DASHBOARD_PASSWORD = "..."   # необязательно; без него дашборд открыт по ссылке
```

`DASHBOARD_PASSWORD` включает простую защиту паролем: пока ключа нет,
страница доступна всем, у кого есть адрес.

## Что где

| Файл | Отвечает за |
|---|---|
| `app.py` | Сборка страницы: статус, период, метрики, графики |
| `data.py` | Выборки из Supabase — с постраничным обходом и кэшем |
| `insights.py` | Выводы словами: что изменилось, куда сместился пик, прогноз |
| `theme.py` | Палитра под светлую и тёмную тему, карточки |
| `config.py` | Пять настроек: ключи, магазин, интервал обновления |

## Две вещи, на которых легко ошибиться

**Постраничная выборка обязательна.** PostgREST отдаёт максимум 1000 строк за
запрос. Выборка без пагинации возвращала свежую тысячу событий и молча
занижала месячные цифры — без единой ошибки в логах. Любой новый запрос к
`visits` должен идти через `_fetch_all_pages`.

**Обращение к `st.secrets` без файла секретов бросает исключение** и роняет
страницу до первой отрисовки, а не возвращает пустое значение. Только через
`secret()` в `app.py`.

## Ускорение на больших объёмах

Тепловая карта и тренды считаются по представлению `hourly_stats`, если оно
есть в базе: 30 дней данных превращаются примерно в 500 строк вместо десятков
тысяч. Если представления нет, тот же расчёт выполняется на клиенте — дашборд
работает, просто медленнее. SQL представления лежит в основном репозитории.
